Altasks is an AI-powered task management and productivity assistant designed to help users create, organize, prioritize, and track their tasks efficiently. The application provides AI-powered natural-language task creation, intelligent task prioritization, daily planning, overdue task detection, productivity analytics, and AI-generated productivity insights. It is built using React, Vite, Tailwind CSS, Node.js, Express.js, PostgreSQL, JWT authentication, and the Gemini API.
